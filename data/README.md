# Dataset format

FireLam training data is **JSONL** (one JSON object per line), chat-formatted:

```json
{"messages": [
  {"role": "system", "content": "You are FireLam, an AI assistant specialized in coding and reasoning."},
  {"role": "user", "content": "Write a Python function to reverse a linked list."},
  {"role": "assistant", "content": "Here's an iterative solution:\n\n```python\ndef reverse_list(head):\n    prev = None\n    while head:\n        head.next, prev, head = prev, head, head.next\n    return prev\n```\n\nThis runs in O(n) time and O(1) space."}
]}
```

Rules:

- Every line must be valid JSON with a top-level `"messages"` array.
- Roles must be one of `system`, `user`, `assistant`, alternating `user`/`assistant`
  (an optional single `system` message may lead).
- Keep the `system` message consistent with `configs/model_config.yaml` unless you're
  intentionally training persona variation.
- No empty `content` strings.
- For coding data: include the language in fenced code blocks (` ```python `, etc.) —
  this matches how the base tokenizer's chat template and most benchmarks expect code.

## Recommended data mix (starting point)

| Category | Share | Source ideas |
|---|---|---|
| Coding & debugging | 35% | Real bug-fix diffs, code review Q&A, competitive programming, your own PGC/plugin codebases (sanitized) |
| Reasoning & math | 20% | Step-by-step solved problems, chain-of-thought explanations |
| Instruction following | 20% | Varied task instructions with clear success criteria |
| Multi-turn conversation | 15% | Realistic back-and-forth, clarifying questions |
| Agentic / tool-use | 10% | Tool-call transcripts (function calling format), planning traces |

## Validate before training

```bash
python data/validate_dataset.py --path data/your_dataset.jsonl
```

This checks JSON validity, role ordering, empty content, and token-length distribution
(flagging examples that will get truncated at `max_seq_length`).

## Where to source data (legally)

- Your own PGC codebases, config files, support Q&A (sanitize secrets/PII first).
- Open datasets with permissive licenses: OpenHermes-2.5, Magicoder, Evol-Instruct-Code,
  MetaMathQA, GSM8K, CodeAlpaca — check each dataset's license before redistributing.
- Synthetic data generated by a strong open model (self-instruct style), clearly labeled
  as synthetic in your dataset card.

Do **not** scrape or include data from proprietary model outputs whose terms of service
prohibit using them to train a competing model.
